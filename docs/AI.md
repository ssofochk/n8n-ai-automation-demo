# Использование AI

Инструмент: ChatGPT. Исходный запрос: «я хочу пикми розовый калькулятор с аниме девочками»; затем просьба дополнить ZIP с существующим калькулятором по всем требованиям практики 8. AI предложил концепцию с двумя полями, операциями, карточкой результата и kawaii-маскотами. Макет экспортирован в HTML (`prototype.html`), состояния переключаются вручную; это не работающий API. Итоговый интерфейс использует те же элементы, цвета и структуру.

Примеры запросов для воспроизведения (формулировки, а не журнал отдельных реально отправленных сообщений):
- Макет: «Сделай pink kawaii калькулятор с двумя anime chibi, двумя полями, операциями, состояниями initial/input/loading/success/empty/error».
- Интерфейс: «Используй готовые Bootstrap 5 card, form-control, btn-group, alert и spinner; подключи FastAPI к существующим функциям Python, обеспечь клавиатурную доступность и блокировку повторной отправки».
- Тесты: «Напиши Playwright-тесты видимого поведения; подмени API для успеха, задержки, пустого ответа и ошибки, проверь единственный запрос и отдельный сценарий с реальным API».

Уточнения в ходе разработки: вместо React/MUI выбран Bootstrap + JS, поскольку npm registry недоступен в среде AI; исходные функции не переписывались. Добавлены явные сообщения валидации, флаг pending до запроса, локальная библиотека CSS, отдельные проверки API. Рендер исходного экрана получен через Chromium set_content с локальными CSS/SVG; это не снимок работающего HTTP-приложения. Реальный API отдельно проверен TestClient. Браузерные проверки на HTTP в этой среде заблокированы. Студенту необходимо самостоятельно проверить макет, выполнить тесты и зафиксировать свои фактические исправления/результаты перед сдачей.
